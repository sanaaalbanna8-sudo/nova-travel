# الاجتماع الطارئ | The Emergency Meeting
## نوفا ترافل | Nova Travel

تطبيق صفي بالعربية لحصّة **Pearson BTEC Level 3 — Unit 1 — Learning Aim B**. تدير المعلمة عشرين حالة لشركة حجوزات وسياحة وفنادق، ويفتح باب التصويت من جهازها فقط. كل رقم من 1 إلى 17 يفتح دوراً واحداً داخل ثلاثة مستويات: استراتيجي، وإداري، وتشغيلي.

## التشغيل على لابتوب الحصة

يلزم Node.js 18 أو أحدث.

```bash
npm install
npm run dev
```

يظهر في الطرفية الرمز ورابطان لكل عنوان شبكة. افتحي **المضيفة** على لابتوب الرئاسة، وشاركي **البنات** مع الأجهزة. لا تستخدمي الرابط الذي يحتوي على `localhost` إلا على جهازك.

- المضيفة: `http://عنوان-الشبكة:5173/host`
- البنات: `http://عنوان-الشبكة:5173/join`

إذا طلب جدار حماية ويندوز الإذن، اسمحي لـ Node بالاتصال على الشبكة الخاصة.

**رمز المضيف الافتراضي:** `NOVA-BTEC`

لتغييره في الجلسة الحالية:

```bash
set HOST_PIN=رمز-جديد
npm run dev
```

في PowerShell:

```powershell
$env:HOST_PIN="رمز-جديد"
npm run dev
```

## سير الحصة

1. وزّعي الأرقام 1–17. دليل الأدوار موجود في لوحة المضيف.
2. يدخل كل طالب رقمه ويتأكد من المسمى قبل دخول القاعة.
3. الحالة تُناقش والتصويت مغلق.
4. **فتح باب التصويت** يفعّل الخيارات A و B و C على أجهزة الطلاب.
5. **إغلاق التصويت وعرض النتائج** يُظهر التوزيع العام وتوزيع المستويات الثلاثة.
6. **الحالة التالية** تحفظ نتيجة الحالة الحالية وتفتح الحالة التي تليها والتصويت مغلق.
7. العودة إلى حالة سابقة تسترجع تصويتها.
8. **وضع العرض** يخفي ملاحظات المعلمة وكشف الأسماء عند استخدام جهاز العرض.
9. **كشف أصوات الأدوار** للمضيفة بعد إغلاق التصويت، ولا يُعرض على الطلاب.

## المزامنة

الخادم يحفظ حالة الاجتماع في `server/data/state.json`. حين يُفتح التصويت أو يُغلق أو تتغير الحالة، تصل اللقطة إلى الأجهزة المتصلة فوراً عبر WebSocket. تحديث الصفحة لا يمسح الأصوات ما دام الخادم يعمل.

إذا فُتحت الواجهة من غير خادم، تعمل مزامنة تجريبية بين تبويبات الجهاز نفسه عبر `localStorage`. هذه التجربة لا تصل إلى هواتف الطلاب.

## النشر على الإنترنت

مدارس كثيرة تفصل أجهزة الطلاب عن لابتوب المعلمة. في هذه الحالة انشري **الخادم نفسه**، لا الواجهة وحدها.

### Render

1. ارفعي المشروع إلى مستودع Git.
2. أنشئي Web Service من الملف `render.yaml` أو بالإعدادات: البناء `npm install && npm run build`، والتشغيل `node server/index.js --prod`.
3. أضيفي المتغير `HOST_PIN` برمز لا يعرفه الطلاب.
4. بعد اكتمال النشر، شاركي رابطين من الخدمة نفسها: `https://...onrender.com/host` للمضيفة و`https://...onrender.com/join` للبنات.

### Vercel أو Netlify

الاستضافة الساكنة تنشر الواجهة فقط، ولا تبقي تصويتاً مشتركاً بين الهواتف. للتجربة على جهاز واحد تكفي المزامنة المحلية. لحصّة حقيقية استخدمي التشغيل المحلي أو Render.

صفحات GitHub تنشر الرابطين `.../host` و`.../join`، وهما للعرض. التصويت المشترك بين اللابتوب وأجهزة البنات يبقى على خادم Node.

إذا كانت الواجهة على Vercel والخادم على Render، ابنِ الواجهة بعد ضبط:

```bash
VITE_SYNC_URL=wss://اسم-الخدمة.onrender.com/ws
VITE_SYNC_HTTP=https://اسم-الخدمة.onrender.com
```

## تعديل الحالات

الحالات في `src/data/cases.json` والأدوار في `src/data/roles.json`. بعد التعديل:

```bash
npm run check
```

الأمر يتحقق من اكتمال العشرين حالة وسبعة عشر دوراً، ومن أن إغلاق التصويت والانتقال بين الحالات يحفظان الأصوات.

مصطلحات الامتحان الإنجليزية تظهر بين قوسين داخل العربية، مثل Validation و Audit Trail، لأن طلاب BTEC يحتاجونها في ورقة الاختبار.
